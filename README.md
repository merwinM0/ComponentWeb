# ComponentWeb

一个基于 **Bun + HTML + CSS + TypeScript** 的可视化组件布局工作台。使用真实 DOM 和 Shadow DOM，无需前端框架。

![](/home/mo/mon/my_programs/ComponentWeb/home.png)

## 功能

- 内置 138 项素材，包括常用组件、HTML 标签和布局容器。
- 支持拖放、缩放、多选、对齐，以及自由 / Flex / Grid 布局。
- 右键原位编辑组件，修改内部标签的文本、位置、尺寸和颜色。
- 支持嵌套组装，并将自定义组合保存到组件库复用。
- 提供预览、撤销 / 重做和浏览器本地自动保存。
- 首页管理全部布局，支持一键新建、继续最近布局和定位搜索；进入编辑器后，可切换最近修改的 5 个布局。

## 启动

先安装 [Bun](https://bun.sh)，然后运行：

```bash
bun install
bun run dev
```

打开 http://localhost:3000 。

## 基本使用

1. 在首页选择已有布局，或点击「新建布局」进入空白工作区。
2. 从左侧组件库拖入素材，或点击「添加」。
3. 选中组件，在右侧修改布局、内容和样式。
4. 右键选择「编辑组件」，修改内部内容；空间不足时先扩大编辑框。
5. 将散件「组装本层」或删除后，点击「完成本层」。

点击导航栏的当前布局名称，可切换最近修改的 5 个布局；选择「查看全部布局」或点击品牌标志返回首页。「保存布局」与自动保存均更新当前布局。刷新布局地址会回到该布局，直接打开首页则先选择布局。

首页交互背景铺满整个视口，留白和列表区域同样响应鼠标，滚动后也不偏移；标题、按钮和内容宽度保持稳定。默认静止，仅鼠标经过或点击时反馈；效果可关闭，并遵循系统「减少动态效果」设置，不影响布局操作。

顶栏的 ☀ / ☾ 按钮可切换亮暗主题，编辑页位于「保存布局」右侧。默认暗色，亮色网格默认白底黑线。画布自定义配色自动记在浏览器；切换主题后使用并记住对应默认网格配色，不新增配色方案收藏，也不改变组件自己的颜色或布局修改时间。

电脑横屏采用 **16:9 画布，默认等比适应工作区**，不再用超大像素画布铺满。窗口变化只改变显示倍率，不修改组件坐标或尺寸；可手动选择 100% 查看真实像素。上一版已放到远处的内容保留旧范围兼容显示，不裁剪。手机、竖屏和其他比例仍列在[后续待办](./ROADMAP.md#明确保留的后续待办多设备与多比例)。

布局只保存在当前浏览器，不提供后端或跨设备同步。未完成的组件编辑草稿不会自动保存，完成编辑后才能切换布局。

## 检查与构建

```bash
bun test
bun run typecheck
bun run build
```

构建产物位于 `dist/`。浏览器回归检查：

```bash
bunx playwright install chromium
bun run test:browser
```
