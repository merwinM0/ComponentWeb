# 三款 SVG 容器背景

本轮已设计并接入容器背景。最初的深色折角稿不采用，也不作为这次设计的配色或形状依据。**当前工作台和常用组件都只是功能测试样式，整体配色与布局可以调整**；全面重做常用组件视觉已单独记入 [ROADMAP.md](../ROADMAP.md#明确保留的后续待办重做全部常用组件样式)。

[打开三款设计对照页](./svg-backgrounds.html)（含 HTML 文案示例，可直接在浏览器打开本地文件）。

## 设计方向

三款使用独立的浅色配色，不随工作台暗色 / 亮色切换而变色；不是把当前方角暗色外壳机械换皮。无字体 / 图片依赖，无动画、发光、滤镜或复杂渐变。

| 款式 | 设计稿 | 视觉与用途 | 最小内部设计尺寸 |
| --- | --- | --- | --- |
| 折页纸张 | [svg-paper.svg](./svg-paper.svg) | 奶油纸面、杏色折页；用于说明、笔记和内容卡片 | 192×144px |
| 镂空票券 | [svg-ticket.svg](./svg-ticket.svg) | 珊瑚票面、双侧真实透明缺口、虚线票根；用于活动、优惠和摘要 | 216×120px |
| 对话气泡 | [svg-bubble.svg](./svg-bubble.svg) | 鼠尾草绿圆润面板、底部尾角；用于提示、问答和留言 | 192×144px |

静态设计稿均为 360×240px。工作台实现是参数化路径，不是将静态文件粗暴拉伸成任意尺寸。SVG 不包含文字、输入或交互；子组件仍是可编辑的真实 DOM。

## 几何与布局契约

- 外部占位 / 选中 / 缩放框仍为矩形；按现有规则参与同级碰撞与对齐。透明缺角不等于可与其他根组件重叠。
- SVG 可见轮廓不使用矩形底色补满，选中或原位编辑时也保持缺口透明。
- 固定几何预留（上 / 右 / 下 / 左）：纸张 36 / 36 / 18 / 18px，票券 20 / 52 / 20 / 28px，气泡 20 / 20 / 44 / 20px。
- 在该区域内预留边线，得到内容安全区；再将用户已有 padding 应用一次，得到实际布局区域。不会增加可调外边距，也不会把 padding 算两遍。
- 自由布局子项坐标从实际布局区域起算；Flex / Grid 在同一区域内排版。切换皮肤保留子项设计坐标，不偷偷重排自由布局子项；如果剩余区域放不下，整次切换失败，可先扩大内部设计尺寸。
- 选中 / 当前原位编辑的 SVG 容器显示安全区虚线；预览隐藏。拖入 SVG 容器必须落在实际布局区域，缺角、票根和尾角不是子项落点。
- SVG 装饰不参与内部标签编辑，不能误删背景路径。安全区既用于 DOM 定位，也用于找空位、尺寸校验、原位散件与组装。

## 缩放与样式

修改内部设计宽高会重建 SVG 路径和内容区域；不改变设计像素中的折页、缺口、尾角参数。修改外部显示宽高时背景和内容使用同一个现有变换。当前外部 X/Y 可独立缩放，仍可能改变折角角度；保持比例需输入相同比例，锁比例作为后续功能。

选择款式会应用该款示例的背景、文字、边框、强调色，可继续使用组件配色面板自定义。切回普通矩形保留当前配色。矩形的圆角参数不控制 SVG 自定义轮廓；边框颜色、粗细、虚线 / 点线 / 隐藏仍作用于 SVG 主轮廓。

## 接入范围

1. `components/container/skins.ts`：可信背景模板、参数化路径、配色与最小尺寸。
2. `core/container-geometry.ts`：唯一的安全区 / 内容区计算，供渲染和边界模型共同使用。
3. `editor/container-surface.ts`：SVG、辅助线与内容 DOM 的定位；背景不拦截交互。
4. 属性面板「容器背景」：三个缩略预览与普通矩形入口；预览模式不可修改。
5. 节点仅增加白名单 `skin` ID；保存、复制、组合快照与撤销重做保留它。旧布局缺少此字段时仍使用原矩形背景，不批量改色或迁移坐标。

本轮不开放任意 SVG 导入、不支持轮廓互嵌、不自动沿不规则路径绕排文字。外部 SVG 安全导入、精确轮廓命中与多内容区仍列为待办。
